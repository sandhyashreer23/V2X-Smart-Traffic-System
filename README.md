AI-Based V2X Smart Traffic and Collision Alert System

Overview
This project simulates Vehicle-to-Everything (V2X)
communication using Python and Streamlit.

Features
- Vehicle Simulation
- Collision Detection
- AI Traffic Prediction
- Emergency Vehicle Priority
- Smart Traffic Signal Control
- Traffic Analytics
- SQLite Database Storage

Technologies
- Python
- Streamlit
- Pandas
- Scikit-Learn
- Plotly
- SQLite

How to Run

pip install -r requirements.txt

streamlit run app.py
